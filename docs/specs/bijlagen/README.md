# Bijlagen bij de specs

Hulpmateriaal dat de specsessie op 2 oktober 2026 heeft gemaakt. Geen besluiten;
die staan in `../00-overzicht.md`.

- `repo-inventaris.md`: technische inventaris van de repo op de startcommit
  (routes, componenten met props, messages-sleutels, tokens, registers, checks).
- `samenvattingen/context-<nn>.md`: samenvatting van één pagina per groot
  contextbestand, met feiten, voorstellen, open vragen en tegenstrijdigheden.
  `context-research.md` vat de schrijfstijlanalyse en het lokale onderzoek samen.
- `spec-vorm.md`: de verplichte opbouw van elke spec, met uitleg per sectie.
